## Selected work

### [MovieFlix](https://github.com/Alb7n/movieflix)
A movie discovery application with search, genre browsing, trending titles and a persistent watchlist. Includes a server-side TMDB proxy so the API token is not exposed in browser code.

**Stack:** JavaScript · HTML · CSS · Vercel serverless functions · TMDB API

### WeCare — Food delivery application
A full-stack food delivery project with cart state management and an admin workspace. The admin side includes role-based access, audit logging and data export.

**Stack:** Next.js · React · Prisma · SQLite

### Resume screening system
A resume-matching prototype that parses PDF and DOCX files, compares candidate content with a job description, and ranks matches using TF-IDF and cosine similarity.

**Stack:** Python · Flask · NLP · TF-IDF

### Blockchain certificate verification
A project exploring verifiable digital certificates using blockchain records and IPFS-based document storage.

**Concepts:** Smart contracts · NFTs · IPFS
